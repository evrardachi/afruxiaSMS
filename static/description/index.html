📱 Afruxia SMS pour Odoo 19

Module d'envoi de SMS via l'API Afruxia

🚀 Fonctionnalités

✅ Configuration simple de l'API
Configurez facilement vos identifiants API Afruxia avec test de connexion intégré.
✅ Envoi de SMS
Envoyez des SMS individuels ou en masse directement depuis Odoo.
✅ Historique complet
Conservez l'historique de tous vos SMS envoyés avec leur statut.
✅ Gestion des erreurs
Détection automatique des erreurs avec possibilité de réessayer l'envoi.
✅ Compteur de caractères
Visualisez en temps réel le nombre de SMS nécessaires selon la longueur du message.

⚙️ Installation

  1. Copiez le module dans le dossier addons de votre Odoo
  2. Redémarrez le serveur Odoo
  3. Activez le mode développeur
  4. Mettez à jour la liste des applications
  5. Installez le module Afruxia SMS

📖 Configuration

  1. Allez dans Afruxia SMS > Configuration > Configuration API
  2. Créez une nouvelle configuration
  3. Renseignez vos identifiants API Afruxia
  4. Testez la connexion
  5. Marquez-la comme configuration par défaut
